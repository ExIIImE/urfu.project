# Кубик — учебный интернет-магазин гаджетов

Фронтенд-проект на HTML, CSS и JavaScript. Сборка и установка зависимостей не нужны.

## Запуск

Доступен на Github Pages

Откройте index.html в браузере или запустите локальный сервер в папке проекта:

python -m http.server 8765 --bind 127.0.0.1

После запуска сайт доступен по адресу http://127.0.0.1:8765/.

## Структура

- index.html — главная страница, каталог, диалоги товара и корзины.
- style.css — оформление и адаптивная верстка.
- script.js — каталог, поиск, фильтрация, сортировка, карточки и корзина.
- assets/*.webp — изображения для сайта.

## Возможности

- Главная страница и каталог с маршрутизацией через URL-хеш.
- Поиск по названию, фильтрация по категории и сортировка.
- Просмотр описания товара в диалоге.
- Корзина: добавление, изменение количества, удаление, общая сумма.
- Сохранение корзины в localStorage между перезагрузками.
- Адаптивный интерфейс для компьютера, планшета и телефона.

Проект не содержит серверной части. Оформление и оплата заказа не реализованы. Названия, цены и изображения товаров используются для демонстрации интерфейса.
